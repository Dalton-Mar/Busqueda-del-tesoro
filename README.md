# Busqueda-del-tesoro 🕵️
En este juego el usuario debe encontrar un tesoro que esta oculto en unas coordenadas

En este juego el jugador tendra que buscar el tesoro que esta oculto en el eje X y en el eje Y. para ganar debe poner lar coordenadas en un rango del 1 al 5. Se tienen 5 oportunidades para encontrar el tesoro, de lo contrario el jugador perdera.
